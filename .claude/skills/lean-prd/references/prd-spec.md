## ID 사슬

```
H# (가설) ──▶ M# (지표) ──▶ E# (실험) ──▶ MS# (마일스톤) ──▶ P# (Pivot 옵션)
```

- 모든 H# 는 M# 과 E# 을 하나 이상 가진다.
- E# 는 존재하는 H#, M# 을 가리킨다. MS# 는 H# 와 P# 를 가리킨다.
- 표의 ID 는 `H1`, `M1`, `E1`, `MS0`, `P1`, `R1` 형식이다.
