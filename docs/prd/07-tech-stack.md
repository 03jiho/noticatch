# 07. 기술 스택

## 계층별 스택

| 계층 | 선택 | 근거 | 대안 | 월 비용 | 전환 조건 |
|---|---|---|---|---|---|
| 수집 | Python + requests + BeautifulSoup | 학교 게시판 대부분이 정적 HTML이고, 이미 Python 코드가 있다 | Playwright | 0원 | 자바스크립트 렌더링 게시판이 대상의 20% 를 넘으면 Playwright 도입 |
| 마감일 추출 | 정규식 규칙 (`noticatch/deadlines.py`) | E1 을 하루 안에 돌릴 수 있는 가장 싼 방법이고 규칙 추가가 빠르다 | LLM 후보 추출 + 규칙 검증 | 0원 | E1 정확도가 90% 미만이면 LLM 보조 도입 (월 1만 원 이내일 때만) |
| 저장소 | SQLite 파일 | MS0~MS2 는 사용자 100명 미만이라 파일 하나로 충분하다 | PostgreSQL | 0원 | 사용자가 100명을 넘거나 동시 쓰기 충돌이 월 3회 이상 나면 전환 |
| 백엔드 | FastAPI | 자동 문서가 나오고 `.ics` 피드 엔드포인트가 간단하다 | Flask | 0원 | 로그인이 필요한 MS2 시작 시, 또는 `.ics` 요청이 하루 1,000회를 넘으면 도입. 그 전에는 정적 파일로 대체 |
| 프런트 | 정적 HTML + GitHub Pages | MS1 까지 화면이 한 장이고 서버가 필요 없다 | Next.js (Vercel) | 0원 | 로그인이 필요한 MS2 시작 시, 또는 월 방문 1만 회 초과 시 |
| 스케줄·배포 | GitHub Actions cron (30분) | 서버 없이 주기 실행되고 이미 CI 를 쓰고 있다 | Cloud Run + Scheduler | 0원 | 1회 실행이 5분을 넘거나 월 2,000분 한도의 70% 를 쓰면 전환 |
| 캘린더 | `.ics` 구독 피드 (RFC 5545) | 구글·애플 캘린더가 링크 구독을 지원하고 연동 승인이 필요 없다 | Google Calendar API | 0원 | 즉시 반영을 원하는 사용자가 20% 를 넘으면 API 연동 |

## 비용 요약

MS0~MS2 의 현금 비용은 **월 0원**이다. 상한은 월 1만 원이고, 넘는 항목(LLM 호출 등)은 전환 조건을 만족하더라도 상한 안에서만 도입한다.
