## 3. 채용 / 외주 우선순위

1. 도메인 검수 — 이유: MS0에서 추출 정확도가 낮게 나오면 사람의 검수가 병목이 된다 — 시점: MS0 종료 직후 — 예산: 0원(지인, 식사 제공 월 1만 원 이내)
2. UX 피드백 — 이유: MS2의 첫 구독 3분(H5) 관찰에 필요 — 시점: MS1 통과 후 — 예산: 0원
3. 개발 인력은 MS3 이후 구독자가 100명을 넘고 게시판이 5곳을 넘을 때까지 두지 않는다. 지금 병목은 개발이 아니라 검증이다.
