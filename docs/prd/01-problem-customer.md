# 01. 문제와 고객

## 고객 세그먼트

- **1차 고객**: 장학금, 수강신청, 교환학생, 인턴 같은 **마감이 있는 공지**를 챙겨야 하는 대학 재학생 (학부 2~4학년, 휴학·복학 예정자 포함)
- **하위 세그먼트**: 교환학생 준비자, 국가근로장학생 지원자, 대학원 진학 준비자, 학생회 간부(여러 게시판을 대신 확인하는 사람)

## 문제

공지가 학교 홈페이지, 단과대·학과 게시판, 학생지원 사이트, LMS 에 **흩어져 있다.** 학생은 마감이 지난 뒤에야 알거나, 나와 상관없는 공지 수십 건 속에서 필요한 한 건을 찾지 못한다. 공지마다 마감일 표기도 제각각이라(`~12.5(금)`, `2024. 12. 13.(금) 18:00`, `3월11일(수) 12:00`) 읽고 캘린더에 옮기는 일도 수작업이다.

## 기존 대안과 한계

| 기존 대안 | 사용 방식 | 한계 |
|---|---|---|
| 게시판 직접 방문 | 매일 여러 사이트를 열어 확인 | 시간이 들고, 대부분은 나와 상관없는 공지 |
| 학교 앱·카카오톡 채널 | 전체 공지를 그대로 푸시 | 알림 피로로 끄게 되고 일부 게시판만 다룸 |
| 친구·단톡방 전달 | 누가 보면 공유 | 운에 의존하고 늦게 도착 |
| 학교 포털 캘린더 | 학사일정만 표시 | 개별 공지의 신청 마감은 반영되지 않음 |

## 첫 고객(Early adopter) 정의

**장학금이나 교환학생 지원을 앞둔 3~4학년**이다. 마감을 놓치면 금전적 손해가 크고(장학금 등록금 전액 같은 공지가 실제로 올라온다), 공지를 직접 찾아본 경험이 있어 불편을 구체적으로 말할 수 있다. 학과 단톡방과 에브리타임으로 만날 수 있고, 처음 10명은 개인 인맥으로 모집한다.
