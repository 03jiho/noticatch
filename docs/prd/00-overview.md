# 00. 개요

## 한 줄 아이디어

여러 학교 게시판에 흩어진 공지를 모아, 내가 구독한 키워드의 공지만 **마감일과 함께 캘린더로** 알려 주는 서비스 (NotiCatch).

## 현재 결정 상태

- 최근 결정: 아직 없음 (Cycle 1 진행 전). 가장 위험한 가설 H2 의 실험 E1 을 먼저 돌린다.

## 핵심 가설 요약

- ★ **H2 (위험도 20)**: 마감일을 규칙 기반 추출로 90% 이상 맞출 수 있다. 가장 싸게 먼저 검증할 대상으로 선정
- **H1 (20)**: 재학생은 놓친 마감 때문에 키워드 알림·캘린더 방식을 쓰고 싶어 한다. Cycle 2 대상
- **H4 (16)**: D-3, D-1 리마인드가 신청 행동을 늘린다
- **H3 (12)**: 첫 구독이 3분 안에 끝난다
- **H5 (12)**: 새 게시판 추가가 2시간 안에 끝난다

## 문서 지도

| 문서 | 답하는 질문 |
|---|---|
| 01 문제와 고객 | 누가 왜 불편한가 |
| 02 가설 | 무엇이 틀리면 안 되는가, 가장 위험한 것은 |
| 03 지표 | 맞고 틀림을 어떤 숫자로 아는가 |
| 04 MVP | 그 숫자를 얻는 가장 작은 것은 |
| 05 실험 | 어떤 순서로 어떻게 검증하는가 |
| 06 팀 | 누가 하고 Pivot 은 누가 정하는가 |
| 07 기술 스택 | 무엇으로 만들고 언제 바꾸는가 |
| 08 마일스톤 | 어디서 멈추고 결과를 보는가 |
| 09 Pivot 안전장치 | 틀리면 무엇을 바꾸고 어디서 접는가 |
| 10 리스크 | 무엇이 잘못될 수 있는가 |
| 11 사이클 기록 | 실제로 돌려 무엇을 배웠는가 |
