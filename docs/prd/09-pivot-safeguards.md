## 트리거

트리거는 05-experiments 의 통과 기준과 같은 숫자다. 마일스톤 종료 후 3일 안에 측정값과 비교하고, 하나라도 해당하면 해당 P# 를 실행한다. 결과를 본 뒤에 트리거 숫자를 바꾸지 않는다. Pivot 은 비전("마감을 놓치지 않게 한다")은 유지하고 전략의 한 축만 바꾼다.
