## 2. 실험 설계

### E1 — H2 검증

- **Build**: 공개된 학교 게시판 공지에서 마감일이 적힌 줄을 모으고 사람이 정답을 단다. 추출기(규칙 기반)를 그대로 돌리는 평가 스크립트. 사용자 없는 Offline evaluation. 소요 1일, 담당 본인
- **Measure**: 지표 M3 — 일치 건수 / 전체 — 샘플 15건 이상 — 기간 1일
- **Learn**: 90% 이상이면 Persevere(MS1로). 90% 미만이면 곧바로 P1(반자동). 회색 지대는 두지 않는다 — 이 기준(90% / 미만 P1)은 이전 버전 PRD(커밋 75fc283)에서 측정 전에 고정했고, 측정(커밋 1d61656) 이후 이 문서를 규격에 맞춰 다시 쓸 때 **바꾸지 않고 그대로 옮겼다**
- GitHub Issue: `experiment` 라벨, 템플릿 `.github/ISSUE_TEMPLATE/experiment.md`

### E2 — H1 검증 (인터뷰)

- **Build**: 15분 인터뷰 대본(최근 학기 놓친 마감, 현재 대안, 캘린더 사용 여부). 소요 반나절
- **Measure**: 지표 M1 — 인터뷰 응답 — 샘플 10명 — 기간 7일
- **Learn**: 4명 이상이면 통과. 3명 이하면 P2(세그먼트 좁히기). 정성 답변에서 "놓친 적은 없지만 불편" 비율도 기록

### E3 — H1 검증 (랜딩 페이지)

- **Build**: 한 장짜리 랜딩 페이지와 구독 링크 버튼, 이벤트 기록. 소요 1일
- **Measure**: 지표 M2 — `subscribe_click` / `landing_view` — 방문 100회 이상 — 기간 7일
- **Learn**: 30% 이상이면 통과. 15% 미만이면 P2. 15~30%는 회색 지대(문구·채널 변경 후 1회 재측정)

### E4 — H5 검증

- **Build**: 구독 화면(키워드 입력 → 링크 발급). 소요 2일
- **Measure**: 지표 M4 — 관찰 기록과 `subscribe_complete` — 처음 보는 5명 — 기간 3일
- **Learn**: 완료율 50% 이상이고 중앙 180초 이하이면 통과. 완료율 30% 미만이면 P3

### E5 — H3 검증

- **Build**: 리마인드 발송 자동화(D-3, D-1). 소요 2일
- **Measure**: 지표 M5 — 14일 뒤 설문 — 20명을 두 그룹으로 — 기간 14일
- **Learn**: +10%p 이상이면 통과. 미만이고 해지 30% 초과면 P4

### E6 — H4 검증

- **Build**: 구독 완료 화면에 공유 링크 추가, 유입 채널 기록. 소요 반나절
- **Measure**: 지표 M6 — 공유 유입 구독 수 / 기존 구독자 수 — 구독자 20명 이상 — 기간 14일
- **Learn**: 0.3명 이상이면 통과. 0.1명 미만이면 성장 채널 재설계, 두 번 연속이면 Kill 조건 검토

### E7 — H2 재검증 (Cycle 1 이후 추가)

- **Build**: c13(`M. D.` 요일 없는 표기)와 c14(`YYYY/MM/DD`) 결함을 고친 추출기. 평가 코퍼스는 **처음 보는 새 공지만** 쓴다 (E1의 19건으로 다시 재면 과적합이다)
- **Measure**: 지표 M3 — 샘플 새 공지 20건 이상, 가능하면 우리 학교 게시판 포함 — 기간 1일
- **Learn**: 90% 이상이면 MS0 종료(Go). 미만이면 LLM 후보 보강(08 전환 조건)을 검토. 후보·원문 병기(P1)는 정확도와 무관하게 유지한다

## 3. 판단 기준

숫자는 `05-metrics.md` 목표치와 동일해야 한다.

| 실험 | 지표 | 통과 ≥ | 실패 < | 회색 지대 처리 |
|---|---|---|---|---|
| E1 | M3 | 90% | 90% | 없음 (측정 전 고정 기준. 90% 미만은 실패 → P1) |
| E2 | M1 | 40% (4명) | 40% (4명 미만) | 통과/실패 사이 구간 없음. 3명이면 인터뷰 5명 추가 후 재판단 |
| E3 | M2 | 30% | 15% | 문구·채널을 바꿔 1회 재측정, 두 번 연속이면 P2 |
| E4 | M4 | 완료율 50%, 중앙 180초 | 완료율 30% | 화면 문구만 바꿔 5명 추가 관찰 |
| E5 | M5 | +10%p | +5%p | 20명 추가 모집해 재측정 |
| E6 | M6 | 0.3명 | 0.1명 | 공유 문구를 바꿔 1회 재측정 |
| E7 | M3 | 90% | 90% | 없음 (E1과 동일 기준을 새 표본에 적용) |
