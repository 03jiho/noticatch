# 03. 지표

## 지표 정의

| ID | 가설 | 지표 | 측정 방법 | 기준값(숫자) | 데이터 출처 |
|---|---|---|---|---|---|
| M1 | H1 | 최근 한 학기 마감을 놓친 경험이 있는 재학생 비율 | 인터뷰 10명에게 '최근 한 학기에 공지를 늦게 봐서 놓친 마감이 있는가' 질문 | 40% 이상 (4명 이상) | 인터뷰 기록 |
| M2 | H1 | 랜딩 페이지 구독 링크 클릭률 | 클릭 수 / 방문 수 (방문 100회 이상) | 30% 이상 | 랜딩 페이지 이벤트 로그 |
| M3 | H2 | 마감일 추출 정확도 | 실제 공지의 마감일 줄 15건 이상을 사람이 정답을 달고 추출 결과와 대조. 일치 / 전체 | 90% 이상 | 공개 학교 게시판 공지 |
| M4 | H3 | 첫 구독 완료율과 소요 시간 | 5명이 처음 화면에서 구독을 끝내는 과정을 관찰 | 완료율 50% 이상, 중앙 소요 180초 이하 | 관찰 기록 |
| M5 | H4 | 리마인드 수신자와 비수신자의 신청 완료 보고율 차이 | 20명을 두 그룹으로 나누고 14일 뒤 설문 | +10%p 이상 | 설문 응답 |
| M6 | H5 | 새 게시판 1곳 추가 소요 시간 | 게시판 3곳을 추가하며 시간 측정 | 평균 2시간 이하 | 작업 기록 |

## 북극성 지표

**마감 전에 신청을 완료했다고 답한 구독자의 비율.** 제품의 약속("마감을 놓치지 않는다")을 그대로 잰다. 목표는 MS3 종료 시 60% 이상이다.

## 가드레일

좋아져도 나빠지면 안 되는 지표:

- **잘못된 마감일 알림 비율 5% 이하** — H2 의 정확도가 올라도 오탐이 알림으로 나가면 신뢰를 잃는다.
- **사용자당 주간 알림 5건 이하** — 알림 피로 방지.
- **알림 끄기·구독 해지 비율 30% 이하**.
