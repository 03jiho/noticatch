# 실험 사전 시뮬레이션(dry-run) 결과: `cta-style` — 14일치 리허설

> **합성 데이터입니다.** 실제 방문자가 아니라 가상 페르소나 10명의 성향을 돌린 시뮬레이션이며, 데이터 출처는 `metrics/experiment-dryrun.jsonl` 입니다.
> 이 결과는 실험 파이프라인(할당 → 수집 → 분석 → 결정)이 동작함을 보이는 것이고, 실제 사용자 반응의 증거가 아닙니다.

## 가설과 규칙 (실험 전에 고정)

- 가설: 긴급함을 담은 문구('지금 확인하기')가 원본('데이터 보기')보다 버튼 클릭률(CTR)을 올린다.
- 1차 지표: cta_click / exposure (클릭률, CTR)
- 기간: 2026-11-26 ~ 2026-12-09 (14일), 하루 2,000세션
- Persevere 규칙: 상대 증가율 ≥ +10% 이고 p < 0.05 (양측 z 검정). 가드레일 위반 세그먼트가 있으면 '조건부 Persevere'(그 세그먼트는 원본 문구 유지).
- Pivot 규칙: 그 외 전부: 증가율이 +10% 미만이거나 통계적으로 유의하지 않음. 문구가 아니라 다른 가설(예: 마감일 강조, 알림 요약)로 전환한다.

## **사전 시뮬레이션 결과 (실제 운영 전 리허설)**

| variant | 노출 | 클릭 | CTR |
|---|---|---|---|
| `control` (데이터 보기) | 13,928 | 1,571 | 11.28% |

- 상대 증가율 **+8.0%**, 차이의 95% 신뢰구간 [+0.15%p, +1.65%p]

## 현재 기준으로 내리면

**Pivot (방향 전환)**: 버튼 문구 가설은 기준을 넘지 못했다. 다른 가설로 옮긴다.
이유: 유의하지만(p=0.0192) 증가율 +8.0% 이 기준 +10% 에 못 미침.

리허설 결과라 실제 운영 결정이 아닙니다. 실제 결정은 `decision-final.md` 로 자동 생성됩니다.
